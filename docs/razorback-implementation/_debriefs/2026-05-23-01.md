- **DAB data_root path mismatch.** Goal1 spec defaults `data_root: "${DATAAGENTBENCH_DATA_ROOT:-~/dataagentbench/data}"`. Actual data is at `~/git/dataagentbench/data/` (operator-managed clone). With env var unset, plugin reports `dataset not hydrated, found LFS pointer`. **Resolution:** set `DATAAGENTBENCH_DATA_ROOT=~/git/dataagentbench/data` before dispatch. Documented in `docs/superpowers/specs/data-loading-architecture.md`.
- **Reproducibility audit hole on DAB `data_root`.** Frozen spec captures the env-template string, not the resolved path or content hash. Cross-machine + cross-commit drift goes silently undetected. Documented + filed as a future improvement in the architecture doc; could become a code entity if/when captain cares.
- **gb cycle-1 Circle-K race condition.** Concurrent impl worker and validator worker in the same worktree caused non-deterministic file-revert collisions (E1 override partially applied; reverts on subsequent reads). Worker correctly stopped and surfaced. Caused captain's "do zb only" directive earlier to be necessary. **Mitigation worth considering:** never dispatch a fresh validator while impl is still running on the same worktree (treat as a stage-bisection invariant in the FO contract).
- **gb plan-stage override-message ordering.** Captain's "use sha256 digest as canonical" override message arrived after worker had already committed the `@latest` example. Validation cycle 1 correctly caught this as a real AC-1 gap; cycle 2 applied the override. Workflow-level lesson: late-arriving overrides on impl workers can still ride a feedback-reject cycle cleanly; the cost is one cycle.

## Issues — Spacedock

- **Worker SendMessage delivery vs in-flight tool calls.** When FO sends a captain decision to an impl worker that is mid-bash-tool-call, the worker doesn't see the message until its next idle. Caused captain's "do zb only" and the gb E1 override timing. May be a hard constraint of the runtime; worth a small note in the operating contract that captain overrides need at least one tool-boundary to land.
